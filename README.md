# 🎧 PesonaHelpdesk

> **A sleek, modern, and PWA-ready Helpdesk & Ticket Management System built with Flask, SQLAlchemy, and Bootstrap 5.**

PesonaHelpdesk streamlines IT and unit support workflows with end-to-end status tracking, real-time background polling, customizable support notes, and an AI-powered issue formatter.

---

### ✨ Key Features

- **⚡ Real-Time Notifications & Force Alerts:** Background badge polling with sound chime, flashing tab titles, and PWA browser notifications.
- **🤖 AI-Assisted Ticket Formatting:** Built-in template generator to instantly turn raw problem descriptions into structured support tickets.
- **🌙 Zero-Flicker Dark Mode:** Native `localStorage` theme state executed before page render for seamless navigation.
- **📊 Admin Control Center:** Full filtering by requester, status, and custom search with instant **Excel (.xlsx)** export via SheetJS.
- **📝 Dedicated Support Notes:** Real-time feedback thread between admins and requesters directly on ticket rows.
- **📱 Progressive Web App (PWA):** Installable on desktop and mobile devices out of the box.
